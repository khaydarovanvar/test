# STEMCO English — Logo

Redesign of the STEMCO Science logo for the **English** direction, per the brand
instruction sheet: same mark and wordmark, with the subject color changed to the
blue from the instruction box.

## Files

| File | Description |
|---|---|
| `stemco-english-logo.svg` | Master vector logo (transparent background, all text converted to outlines — no fonts needed) |
| `stemco-english-logo.png` | High-resolution PNG, transparent background (1440 px wide) |
| `stemco-english-logo-white-bg.png` | High-resolution PNG on white background |
| `stemco-english-color-spec.png` | Color specification card (Science reference + English) |

## English subject color

Characteristics in the same format as the Science color:

> **BRIGHT CYAN BLUE**
> **PANTONE: 306 C**
> **HEX COLOR: #00B5E2;**
> **RGB: (0,181,226)**
> **CMYK: (100,20,0,11)**

Notes:
- PANTONE 306 C is the closest solid coated color to the bright cyan shown in the
  instruction box (the raw on-screen box color is pure cyan `#00FFFF`, which is
  outside the print gamut; 306 C is the standard print-safe equivalent).
- CMYK values are derived from the HEX/RGB values with the standard conversion.

## Other colors and fonts (unchanged from brand guidelines)

- Wordmark dark: **#333F48** (dark slate, ≈ PANTONE 432 C), RGB (51,63,72)
- Main font (text/body): Roboto
- Secondary font (headers): Roboto Slab
- Logo text font: VOGUE (approximated in the vector with Nunito Black outlines)
- Logo slogan font: Covered By Your Grace (Google font) — used for "English"
